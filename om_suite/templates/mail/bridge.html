Setup (ek baar)

  1. Extension download karein: ⬇ om-suite-mail-bridge.zip (pehle se purane "Auto Bill Intelligence" / "OM Report AI" bridge extensions ho to unhe remove kar dein).
  2. Thunderbird → Add-ons and Themes → ⚙ → Debug Add-ons → Load Temporary Add-on → zip ke andar ki manifest.json chunein (zip ko extract karke). Permanent install ke liye extension ko sign karwana padta hai — README me likha hai.
  3. Extension ke Options me neeche wala connection code paste karke Apply code & connect dabayein. Bas — URL, username aur token apne aap bhar jate hain.
  4. Wapas Mail Center me jayein: Test mode me ek mail bhej ke dekhein (Thunderbird khula rakhein).
